# libfintx.Swift
[![License: LGPL v3](https://img.shields.io/badge/License-LGPL%20v3-blue.svg)](https://www.gnu.org/licenses/lgpl-3.0)

This library holds functions to handle SWIFT messages. It is used by [libfintx.FinTS](https://www.nuget.org/packages/libfintx.FinTS).

# Features

* MT940 account statements (`MT940Parser`)
* MT942 interim transaction reports
* MT535 securities statements (`MT535Parser`)
