# libfintx.Sepa
[![License: LGPL v3](https://img.shields.io/badge/License-LGPL%20v3-blue.svg)](https://www.gnu.org/licenses/lgpl-3.0)

This library holds functions to handle the SEPA standard. It is used by [libfintx.FinTS](https://www.nuget.org/packages/libfintx.FinTS).

# Features

* SEPA credit transfers: pain.001.001.03, pain.001.002.03 and pain.001.003.03
* SEPA direct debits: pain.008.002.02
* Reduce text to the SEPA character set
